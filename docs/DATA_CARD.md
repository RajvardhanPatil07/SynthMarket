# Data Card

SynthMarket intentionally does not bundle proprietary financial history.

## Supported demo source

`yfinance` is supported as a convenient research/demo provider. Provider terms apply to all downloaded data.

## Canonical experiment requirements

Record the dataset identifier, provider/source, version, date range, frequency, timezone/exchange calendar assumptions, corporate-action treatment, missing-data handling, and the SHA-256 fingerprint generated by `synthmarket.data.versioning`.

## Reproducibility

A published result should reference the exact dataset manifest and experiment manifest used for training and evaluation.

## Restrictions

Do not redistribute provider data unless the provider's license permits it. Do not claim synthetic data is historical ground truth.
